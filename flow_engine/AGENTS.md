# flow_engine

## 模块定位
- `flow_engine` 是流程引擎模块。
- 包含流程定义、表单设计器、流程设计器、运行时数据源与流程执行相关能力。

## 目录说明
- `models.py`：流程、表单、节点等核心模型
- `views/`：流程引擎 API
- `page_views/`：设计器等后台页面入口
- `templates/`：流程设计器、表单设计器模板
- `data_sources/`：运行时字段数据源
- `utils/`：流程与表单辅助逻辑

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 优先保持流程定义结构、表单 schema、设计器交互和接口协议稳定。
- 设计器相关前端改动要同步检查模板路径、静态资源路径和测试引用。
- 单文件尽量不要超过 500 行，设计器文件超长时优先拆分。

## 验证建议
- 重点检查：
  - 流程设计器
  - 表单设计器
  - 流程保存/发布/导入导出
  - 字段数据源元信息与运行时解析
