# core.common

## 模块定位
- `core.common` 是项目公共能力模块。
- 它承载跨业务复用的通用模型、工具、管理命令、公共 API。
- 这里应保持低业务耦合，避免写入只服务单一业务线的逻辑。

## 目录说明
- `models.py`：公共数据模型
- `views/`：公共 API 与能力接口
- `apis.py`：API 注册
- `utils/`：通用工具
- `management/`：管理命令
- `plugin_mgr/` / `image_search/`：通用扩展能力

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 优先新增可复用能力，不要把业务特定逻辑塞进 `core.common`。
- 如果只被某个业务 app 使用，应优先落在该业务 app。
- 继续遵循 `core.ninja_extra` 的 API 组织方式。

## 验证建议
- 关注公共能力是否影响多个业务模块。
- 改公共模块前，先评估下游调用面。
