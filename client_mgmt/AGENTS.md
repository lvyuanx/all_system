# client_mgmt

## 模块定位
- `client_mgmt` 是客户管理业务模块。
- 负责客户主数据、客户相关后台能力和移动端接口。

## 目录说明
- `models.py`：客户相关模型
- `views/`：客户业务接口
- `apis.py` / `mobile_apis.py`：后台与移动端 API 注册
- `admin.py`：客户后台管理

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 优先保持客户主数据字段和接口语义稳定。
- 如果只是订单或流程中的客户引用逻辑，不要轻易改动客户主模型定义。

## 验证建议
- 检查客户后台管理、客户查询、移动端客户相关接口。
