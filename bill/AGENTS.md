# bill

## 模块定位
- `bill` 是票据/账单相关业务模块。
- 主要负责票据数据、后台展示、导出或 PDF 相关能力。

## 目录说明
- `models.py`：票据相关模型
- `views/`：账单业务 API
- `page_views/`：后台页面
- `templates/pdf/`：PDF 模板
- `utils/`：账单辅助工具

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 关注账单字段、打印/导出格式、后台展示一致性。
- 涉及模板或导出格式时，尽量保持已有输出兼容。

## 验证建议
- 检查后台账单页面、票据生成、PDF 输出链路。
