# 容器构建启动说明


## 构建镜像

### 使用一键build脚本进行构建

```bash
python run/linuxsvr/build_image.py -p <端口号>
```

## 修改配置

### 进入build目录

执行上一步操作会生成build目录，进入对应的时间目录你会看到config.py文件，修改里面的配置


## 初始化镜像

### 执行初始化脚本

进入build目录内的日期目录内执行命令：

```bash
python init.py
```

命令执行完成后，就会创建好对应的容器。


## 注册Nginx

### 执行Nginx注册脚本

进入build目录内的日期目录内执行命令：

```bash
python register_nginx.py
```

## 初始化数据库

### 创建数据库

根据你刚刚在config.py中的配置创建对应的数据库

### 执行迁移

进入容器内部执行：

```bash
python manager.py makemigrations
python manager.py migrate
```

### 执行数据初始化

进入容器内部执行：

```bash
python manager.py init_sys
```

## 进入浏览器访问：

```
http://ip:port/admin/ 
```

即可进入登录页面（如果要登录的话，还需要使用django的方式创建用户才行）
