# pattern_library

## 模块定位
- `pattern_library` 是版式/模板库业务模块。
- 负责版号、模板库、移动端查询和相关后台能力。

## 目录说明
- `models.py`：版式库相关模型
- `views/`：模板库 API
- `page_views/`：后台页面
- `mobile_apis.py` / `mobile_search_apis.py`：移动端接口
- `templates/`：后台模板

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 优先保持版号、模板库数据结构和查询接口语义稳定。
- 移动端搜索相关接口改动要评估兼容性。

## 验证建议
- 检查模板库后台页面、版式库接口、移动端搜索与查询。
