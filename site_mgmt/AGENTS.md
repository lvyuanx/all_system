# site_mgmt

## 模块定位
- `site_mgmt` 是站点管理与站点上下文相关模块。
- 主要负责站点配置、站点中间件、后台管理和相关 API。

## 目录说明
- `models.py`：站点相关模型
- `views/`：站点接口
- `middlewares/`：站点上下文处理
- `admin_extra/`：后台增强
- `mobile_apis.py`：移动端相关接口

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 站点上下文相关逻辑可能影响全局请求流程，修改中间件时要特别谨慎。
- 优先保持站点切换、站点注入和权限边界稳定。

## 验证建议
- 关注站点识别、中间件行为、后台站点管理以及相关 API。
