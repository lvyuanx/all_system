# staff

## 模块定位
- `staff` 是员工管理业务模块。
- 负责员工资料、人员相关后台页面、接口与业务逻辑。

## 目录说明
- `models.py`：员工相关模型
- `views/`：员工业务 API
- `page_views/`：后台页面视图
- `mobile_apis.py`：移动端接口
- `admin.py`：后台管理配置
- `machine.py`：状态机或流程辅助逻辑

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 优先保持员工主数据语义稳定。
- 如果能力可复用于多个模块，应先考虑是否应放入 `core`。

## 验证建议
- 关注员工列表、详情、状态流转、后台管理页面与移动端接口。
