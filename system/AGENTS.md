# system

## 模块定位
- `system` 是系统级预留 app。
- 当前结构较轻，更多像占位或后续扩展点。

## 目录说明
- `models.py`：系统级模型占位
- `admin.py`：后台注册占位
- `migrations/`：迁移记录

## 通用约定
- 在 Django template 中使用 Vue 时，统一沿用 `[[ ]]` 作为插值分隔符，避免和 Django 的 `{{ }}` 冲突。
- 单个文件尽量不要超过 `500` 行；如果明显超出，应优先按职责拆分。

## 修改约束
- 目前如果没有明确需求，不建议把业务逻辑优先塞到 `system`。
- 若新增系统级能力，先判断它是否更适合进入 `core` 或具体业务 app。

## 验证建议
- 改动前先确认该 app 是否已启用到 `INSTALLED_APPS`。
